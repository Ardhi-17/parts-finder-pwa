# Panduan Upload Excel

1. Gunakan template resmi aplikasi.
2. Jangan ubah nama sheet `MASTER_PARTS`.
3. Jangan ubah nama kolom wajib.
4. Kolom wajib: `equipment_model`, `service_type`, `part_no`, `description`, `qty`.
5. Kolom opsional: `remark`.
6. Upload file melalui menu Upload Excel.
7. Cek error sebelum publish.
